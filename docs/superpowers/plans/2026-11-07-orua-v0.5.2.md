# Orua v0.5.2 实现计划：数据持久化与插件体系

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让升级不再丢用户数据（头像/聊天/API Key），并补全插件体系缺失的入口——使「添加自制插件」在界面上真正可用。

**Architecture:** 数据目录从安装目录迁到 `%LOCALAPPDATA%\Orua`（一次性迁移 + 发布脚本兜底）；后端补 `GET/POST/DELETE /api/v1/plugins` 并在写操作后热重载 EventBus；前端插件页重做为「主区自适应 + 280px 侧栏」两列，新增添加/编辑弹窗。

**Tech Stack:** C++20 / cpp-httplib / nlohmann::json / WPF net8.0-windows / 原生 JS / cmd 批处理 / Node 24 原生 WebSocket + CDP。

**Spec:** `docs/superpowers/specs/2026-11-07-orua-v0.5.2-design.md`

## Global Constraints

- v1–v5.1 全部自动化测试保持全绿，不得为让新断言通过而放宽既有断言。
- 数据迁移必须**幂等**且**失败不丢数据**：目标已存在则跳过；robocopy 失败则中止发布。
- 插件校验以后端为权威，前端只做提前提示（不替代后端校验）。
- 版本号三处同源（csproj / `/health` / index.html 脚注），全部改用 `0.x.y`。
- 不引入新的第三方依赖。

```csharp
private static string DataDir
{
    get
    {
        var overridden = Environment.GetEnvironmentVariable("AI_COMPANION_DATA");
        if (!string.IsNullOrWhiteSpace(overridden)) return overridden;

        var roaming = Path.Combine(
            Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData), "Orua");
        MigrateLegacyDataIfNeeded(roaming);
        return roaming;
    }
}
```

- [ ] **Step 2: 实现一次性迁移**

只在目标不存在或为空时执行；拷贝后删除 WAL/SHM 让 SQLite 重建；异常不阻塞启动。

```csharp
private static void MigrateLegacyDataIfNeeded(string target)
{
    try
    {
        var legacy = Path.Combine(AppContext.BaseDirectory, "data");
        if (!Directory.Exists(legacy)) return;
        if (Directory.Exists(target) && Directory.EnumerateFileSystemEntries(target).Any()) return;

        Directory.CreateDirectory(target);
        foreach (var dir in Directory.GetDirectories(legacy, "*", SearchOption.AllDirectories))
            Directory.CreateDirectory(Path.Combine(target, Path.GetRelativePath(legacy, dir)));
        foreach (var file in Directory.GetFiles(legacy, "*", SearchOption.AllDirectories))
            File.Copy(file, Path.Combine(target, Path.GetRelativePath(legacy, file)), overwrite: false);

        foreach (var sidecar in new[] { "app.db-wal", "app.db-shm" })
        {
            var p = Path.Combine(target, sidecar);
            if (File.Exists(p)) File.Delete(p);
        }
    }
    catch (Exception ex) { /* Debug.WriteLine，退回旧目录 */ }
}
```

- [ ] **Step 3: `publish.cmd` 加迁移子程序**

**注意**：cmd 的 `rem` 注释含全角括号会导致解析失败，注释必须用 ASCII。

```bat
if exist "dist\Orua\data" call :migrate_legacy
if errorlevel 1 exit /b 1
if exist "dist\Orua" rmdir /s /q "dist\Orua"

rem ... 文件末尾 ...
:migrate_legacy
if not exist "%LOCALAPPDATA%\Orua" mkdir "%LOCALAPPDATA%\Orua"
robocopy "dist\Orua\data" "%LOCALAPPDATA%\Orua" /E /XC /XN /XO /NFL /NDL /NJH /NJS >nul
if errorlevel 8 exit /b 1
exit /b 0
```

```powershell

# 迁移后：%LOCALAPPDATA%\Orua 有 app.db / config.json / logs，dist\Orua\data 已删除
```
