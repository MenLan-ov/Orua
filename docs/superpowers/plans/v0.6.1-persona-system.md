# v0.6.1 人设系统 — 实施计划

## 目标

1. 新增「人设」实体，Bot 可绑定；人设影响私聊与群聊的系统提示词。
2. Bot 跟着人设**和**记忆走：两者叠加，顺序稳定。
3. 顺带修掉截图暴露的布局缺陷。

## 任务分解

### T1 后端数据层

- `db.h`：新增 `struct Persona`（id / name / role_text / admin_rules / group_display_name / participation / system_override / builtin / created_at / updated_at）；`struct Bot` 加 `persona_id`。
- `db.cpp`：
  - DDL 加 `personas_v2`（**不复用遗留的 `personas` 表名**，理由见 spec）。
  - `ensureBotCol("persona_id", "ALTER TABLE bots ADD COLUMN persona_id INTEGER NOT NULL DEFAULT 0")`。
  - `rowToBot` 加 `persona_id`（索引 13），`created_at`/`updated_at` 后移到 14/15；四处 `SELECT` 列表同步加列；`createBot`/`updateBot` 的列与占位符同步。
  - `listPersonas` / `getPersona` / `createPersona` / `updatePersona` / `deletePersona` / `setBotPersona`。
  - `applyPersonaToPrompt(basePrompt, personaId)`。
  - 内置人设种子：`personas_v2` 为空时插入三条。

验收：旧库启动后 `bots.persona_id` 为 0，行为不变；重复启动不重复插入种子。

### T2 后端拼接

- `server.cpp`：`resolveBotConfig` 改用 `db::applyPersonaToPrompt`。
- `group_engine.cpp`：`req.messages.push_back({"system", db::applyPersonaToPrompt(...)})`——此前直接用 `bot.system_prompt`，群聊不跟人设。

验收：绑人设后私聊与群聊的系统提示词都含人设文本；解绑后回到原样。

### T3 后端接口

- `personaToJson`；`botToJson` 加 `persona_id`。
- `registerPersonaRoutes`：`GET/POST /personas`、`GET/PATCH/DELETE /personas/{id}`、`PUT /bots/{id}/persona`。
- Bot 的 `POST`/`PATCH` 支持 `persona_id`。
- `main.cpp` 无需改动（种子在 `db::open` 内）。

验收：内置人设删除返回 400；绑定不存在的人设返回 404；PATCH 只改传入字段。

### T4 后端测试

`backend/tests/test_v061.cpp`：
- 种子生成且内置标记正确。
- CRUD + 内置不可删。
- 绑定后提示词跟随、解绑后回到原样、Bot 原提示词保留。
- 覆盖优先于拼接。
- 删除人设解绑引用。
- 人设全空退回原提示词。
- 人设 + 记忆的上下文顺序。

`CMakeLists.txt` 注册 `tests/test_v061.cpp`。

验收：109 用例 / 883 断言全通过。

### T5 前端人设页

- `index.html`：侧栏加「人设」页签；`#view-personas`（标题 + 新建按钮 + 说明 + 列表 + 空态）。
- `app.js`：`loadPersonas` / `renderPersonas` / `personaUsers` / `openPersonaModal` / `save-persona` / `deletePersona`。
- `switchView` 支持 `personas`。

验收：卡片显示人设名、参与度、角色摘要、使用中的 Bot；内置带标记且无删除按钮。

### T6 前端 Bot 详情人设块

- `index.html`：`#bot-detail-persona` 块 + 「切换」按钮，位于 System Prompt 之上。
- `app.js`：`renderBotPersonaBlock`；`pick-bot-persona` 命令（单选弹窗，含「不绑定」选项）。
- 进 Bot 视图时预加载人设，否则会误显示「未绑定」。

验收：绑定后详情显示人设名与参与度；解绑后显示「未绑定人设」。

### T7 人设编辑弹窗

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 旧库升级后说话风格静默改变 | `persona_id` 默认 0；单测钉住「0 时原样返回」 |
| 新表名撞遗留 `personas` 表 | 用 `personas_v2`；`CREATE TABLE IF NOT EXISTS` 在旧表上会静默跳过 |
| 只改了私聊、群聊漏掉 | 拼接下沉到 `db` 层，两边调同一函数 |
| 删除人设留下悬空引用 | `deletePersona` 先解绑再删 |
| 人设弹窗字段多、按钮被挤出 | 内容区滚动 + 底部按钮 sticky |
| 端到端脚本不可重复跑 | 开头清理同名残留；删除断言按 id 而非名字 |
