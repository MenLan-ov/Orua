# Orua v2 实现计划：界面改版、机器人体系与群聊

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 v1 基础上改名 Orua、修复标题栏交互、把「人设」升级为「机器人体系」（每人设 + 可选独立 API 配置），并新增后端驱动的群聊引擎（2-10 个机器人自动连聊），前端按参考图重构为三视图信息架构。

**Architecture:** 三层不变（WPF 壳 → WebView2 → C++ 后端 → WinHTTP → OpenAI 兼容 API）。数据层新增 bots/groups/group_members/group_messages 表并将 personas 数据一次性幂等迁移；后端 `/api/v1/personas` 全面替换为 `/api/v1/bots`，新增 `/api/v1/groups` CRUD + 控制端点 + GroupEngine 状态机（每群一个 std::thread，SSE 广播多客户端订阅）；单聊按会话绑定的机器人解析 API 配置（非空覆盖全局）。标题栏交互改为 JS 事件 → WPF 桥 → 合成 WM_NCLBUTTONDOWN 原生拖拽。

**Tech Stack:** C++20 + cpp-httplib 0.18 + SQLite（WAL/外键）+ WinHTTP + nlohmann/json + doctest；WPF net8.0-windows + WebView2；原生 JS（marked/highlight.js/DOMPurify）；CMake + vswhere；PowerShell 集成脚本。

**Spec:** [docs/superpowers/specs/2026-11-05-orua-v2-design.md](../specs/2026-11-05-orua-v2-design.md)

- 所有 API 沿用 `/api/v1/` 前缀与信封：成功 `{"code":0,"data":...}`，失败 `{"code":<非0>,"message":"..."}`；SSE 事件 `event: <name>` + 单行 JSON `data:`。
- 新增错误码：1001=默认机器人不可删、1002=状态冲突（running 时 start/改成员）、1003=成员数越界、1004=含停用机器人。HTTP 状态仍按语义（400/404/409）。
- LLM_MOCK=1 时假流由 `OpenAiCompatProvider::streamChat` 内部处理（已存在，勿重复实现）；群聊引擎流式调用经注入的 StreamFn 走同一 Provider。

- Produces: `BridgeProtocol.ActionDrag="drag"` / `ActionMaxDbl="maxdbl"` / `ActionSysMenu="sysmenu"`（JS 端 `winMsg(action)` 转发；Task 6/7 的重写版 index.html/app.js 必须保留这些 handler 与 id）。

**背景（根因，已在 v1 系统化调试中确认）：** v1 用 WM_NCHITTEST 对顶层窗口返回 HTCAPTION，但鼠标按下时命中目标是覆盖整个客户区的 WebView2 子窗口，WM_LBUTTONDOWN 作为子窗口客户区消息直接投递，顶层窗口的 HTCAPTION 判定根本不参与该路由，所以拖拽/双击/右键全部失效。可靠路径：JS 转发事件 → WPF 合成 WM_NCLBUTTONDOWN（HTCAPTION）走 DefWindowProc 原生拖拽循环；双击合成 WM_NCLBUTTONDBLCLK；右键 GetSystemMenu + TrackPopupMenu。

```csharp
using System.IO;
using System.Runtime.InteropServices;
using System.Text.Json;
using System.Windows;
using System.Windows.Interop;
using Microsoft.Web.WebView2.Core;

namespace AiCompanion.App;

public partial class MainWindow : Window
{
    private BackendProcess? _backend;

    public MainWindow()
    {
        InitializeComponent();
    }

    private static string WwwrootDir => Path.Combine(AppContext.BaseDirectory, "wwwroot");
    private static string BackendExe =>
        Environment.GetEnvironmentVariable("AI_COMPANION_BACKEND")
        ?? Path.Combine(AppContext.BaseDirectory, "backend", "backend.exe");
    private static string DataDir =>
        Environment.GetEnvironmentVariable("AI_COMPANION_DATA")
        ?? Path.Combine(AppContext.BaseDirectory, "data");

    private async void OnLoaded(object sender, RoutedEventArgs e)
    {
        EnableRoundedCorners();
        try
        {
            _backend = new BackendProcess(BackendExe, DataDir, ReadApiPort());
            _backend.StatusChanged += OnBackendStatusChanged;
            await _backend.StartAsync();
        }
        catch (Exception ex)
        {
            MessageBox.Show(this,
                "后端启动失败：" + ex.Message + "\n\n请确认 backend.exe 已构建并位于程序目录。",
                "Orua", MessageBoxButton.OK, MessageBoxImage.Error);
        }
        await InitWebViewAsync();
    }

    private static int ReadApiPort()
    {
        var cfgPath = Path.Combine(DataDir, "config.json");
        try
        {
            using var doc = JsonDocument.Parse(File.ReadAllText(cfgPath));
            var srv = doc.RootElement.GetProperty("server");
            int port = srv.GetProperty("port").GetInt32();
            if (srv.TryGetProperty("actual_port", out var ap) && ap.GetInt32() > 0)
                return ap.GetInt32();
            return port;
        }
        catch
        {
            return 8765;
        }
    }

    private void OnBackendStatusChanged(string status, string detail)
    {
        if (status == "down")
            PostToJs(new { type = BridgeProtocol.MsgBackendStatus, payload = new { status = "down", detail } });
        else if (status == "up")
            PostToJs(new { type = BridgeProtocol.MsgBackendStatus, payload = new { status = "up", detail = "" } });
    }

    private void PostToJs(object msg)
    {
        try
        {
            Dispatcher.Invoke(() =>
                WebView.CoreWebView2?.PostWebMessageAsJson(JsonSerializer.Serialize(msg)));
        }
        catch { }
    }

    private async Task InitWebViewAsync()
    {
        var env = await CoreWebView2Environment.CreateAsync(
            null, Path.Combine(AppContext.BaseDirectory, "WebView2Data"));
        await WebView.EnsureCoreWebView2Async(env);
        WebView.CoreWebView2.SetVirtualHostNameToFolderMapping(
            "app.local", WwwrootDir, CoreWebView2HostResourceAccessKind.Allow);
        int port = _backend?.ApiPort ?? ReadApiPort();
        await WebView.CoreWebView2.AddScriptToExecuteOnDocumentCreatedAsync(
            $"window.__API_BASE__ = 'http://127.0.0.1:{port}';");
        WebView.CoreWebView2.WebMessageReceived += OnWebMessageReceived;
        WebView.CoreWebView2.Navigate("https://app.local/index.html");
    }

    private void OnWebMessageReceived(object? sender, CoreWebView2WebMessageReceivedEventArgs e)
    {
        try
        {
            using var doc = JsonDocument.Parse(e.WebMessageAsJson);
            if (!doc.RootElement.TryGetProperty("type", out var typeEl) ||
                typeEl.GetString() != BridgeProtocol.MsgWindow)
                return;
            var action = doc.RootElement.GetProperty("payload").GetProperty("action").GetString();
            Dispatcher.Invoke(() =>
            {
                switch (action)
                {
                    case BridgeProtocol.ActionMinimize: WindowState = WindowState.Minimized; break;
                    case BridgeProtocol.ActionMaximize: WindowState = WindowState == WindowState.Maximized ? WindowState.Normal : WindowState.Maximized; break;
                    case BridgeProtocol.ActionClose: Close(); break;
                    case BridgeProtocol.ActionDrag: BeginCaptionDrag(); break;
                    case BridgeProtocol.ActionMaxDbl: SendCaptionDblClk(); break;
                    case BridgeProtocol.ActionSysMenu: ShowSystemMenu(); break;
                }
            });
        }
        catch { }
    }

    // 标题栏交互：v1 的 WM_NCHITTEST→HTCAPTION 方案失效——鼠标按下命中 WebView2
    // 子窗口，其客户区 WM_LBUTTONDOWN 直接投递，顶层窗口 HTCAPTION 判定不参与路由。
    // 现由 JS 转发事件，合成 WM_NCLBUTTONDOWN 走 DefWindowProc 原生拖拽循环。
    private const int WmNcLButtonDown = 0x00A1;
    private const int WmNcLButtonDblClk = 0x00A3;
    private const int WmSysCommand = 0x0112;
    private const int HtCaption = 2;
    private const uint TpmReturnCmd = 0x0100;
    private const uint TpmLeftButton = 0x0000;
    private const uint TpmRightButton = 0x0002;

    private void BeginCaptionDrag()
    {
        var hwnd = new WindowInteropHelper(this).Handle;
        _ = ReleaseCapture();
        _ = SendMessage(hwnd, WmNcLButtonDown, (IntPtr)HtCaption, IntPtr.Zero);
    }

    private void SendCaptionDblClk()
    {
        var hwnd = new WindowInteropHelper(this).Handle;
        _ = SendMessage(hwnd, WmNcLButtonDblClk, (IntPtr)HtCaption, IntPtr.Zero);
    }

    private void ShowSystemMenu()
    {
        var hwnd = new WindowInteropHelper(this).Handle;
        IntPtr menu = GetSystemMenu(hwnd, false);
        if (menu == IntPtr.Zero) return;
        GetCursorPos(out var pt);
        uint cmd = TrackPopupMenu(menu, TpmReturnCmd | TpmLeftButton | TpmRightButton,
                                  pt.X, pt.Y, 0, hwnd, IntPtr.Zero);
        if (cmd != 0) _ = SendMessage(hwnd, WmSysCommand, (IntPtr)cmd, IntPtr.Zero);
    }

    private void EnableRoundedCorners()
    {
        try
        {
            var hwnd = new WindowInteropHelper(this).Handle;
            const int dwmwaWindowCornerPreference = 33;
            const int dwmwcpRound = 2;
            int pref = dwmwcpRound;
            _ = DwmSetWindowAttribute(hwnd, dwmwaWindowCornerPreference, ref pref, sizeof(int));
        }
        catch { }
    }

    [DllImport("dwmapi.dll")]
    private static extern int DwmSetWindowAttribute(IntPtr hwnd, int attr, ref int value, int size);

    [DllImport("user32.dll")]
    private static extern bool ReleaseCapture();

    [DllImport("user32.dll")]
    private static extern IntPtr SendMessage(IntPtr hwnd, int msg, IntPtr wParam, IntPtr lParam);

    [DllImport("user32.dll")]
    private static extern IntPtr GetSystemMenu(IntPtr hwnd, bool bRevert);

    [DllImport("user32.dll")]
    private static extern uint TrackPopupMenu(IntPtr hMenu, uint flags, int x, int y,
                                              int reserved, IntPtr hwnd, IntPtr rect);

    [DllImport("user32.dll")]
    private static extern bool GetCursorPos(out Point pt);

    [StructLayout(LayoutKind.Sequential)]
    private struct Point { public int X, Y; }

    private void OnClosing(object? sender, System.ComponentModel.CancelEventArgs e)
    {
        _backend?.Dispose();
    }
}
```

```cpp
// 手工构造 v1 旧库：sessions 无 bot_id、personas 有激活数据
void makeV1Db(const std::string& path) {
  sqlite3* raw = nullptr;
  REQUIRE(sqlite3_open(path.c_str(), &raw) == SQLITE_OK);
  const char* schema = R"SQL(
    CREATE TABLE sessions (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      title TEXT NOT NULL DEFAULT '新对话',
      created_at TEXT NOT NULL,
      updated_at TEXT NOT NULL
    );
    CREATE TABLE messages (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      session_id INTEGER NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
      role TEXT NOT NULL CHECK(role IN ('user','assistant','system')),
      content TEXT NOT NULL,
      created_at TEXT NOT NULL
    );
    CREATE TABLE personas (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      name TEXT NOT NULL,
      avatar TEXT NOT NULL DEFAULT '🌸',
      greeting TEXT NOT NULL DEFAULT '',
      system_prompt TEXT NOT NULL,
      temperature REAL NOT NULL DEFAULT 0.8,
      is_active INTEGER NOT NULL DEFAULT 0,
      created_at TEXT NOT NULL,
      updated_at TEXT NOT NULL
    );
    CREATE TABLE settings (key TEXT PRIMARY KEY, value TEXT NOT NULL);
  )SQL";
  REQUIRE(sqlite3_exec(raw, schema, nullptr, nullptr, nullptr) == SQLITE_OK);
  const char* data = R"SQL(
    INSERT INTO personas(name,avatar,greeting,system_prompt,temperature,is_active,created_at,updated_at)
      VALUES('旧人设','🌸','你好','你是旧人设',0.7,1,'2026-01-01T00:00:00Z','2026-01-01T00:00:00Z');
    INSERT INTO sessions(title,created_at,updated_at) VALUES('旧会话1','2026-01-01T00:00:00Z','2026-01-01T00:00:00Z');
    INSERT INTO sessions(title,created_at,updated_at) VALUES('旧会话2','2026-01-02T00:00:00Z','2026-01-02T00:00:00Z');
  )SQL";
  REQUIRE(sqlite3_exec(raw, data, nullptr, nullptr, nullptr) == SQLITE_OK);
  sqlite3_close(raw);
}
```

```cpp
Bot createBot(const Bot& b) {
  std::lock_guard<std::recursive_mutex> lock(g_mtx);
  std::string ts = nowIso();
  execute("INSERT INTO bots(name,avatar,greeting,system_prompt,temperature,is_enabled,"
          "api_base_url,api_key_enc,api_model,created_at,updated_at) "
          "VALUES(?,?,?,?,?,?,?,?,?,?,?)",
          {b.name, b.avatar, b.greeting, b.system_prompt,
           std::to_string(b.temperature), b.is_enabled ? "1" : "0",
           b.api_base_url, b.api_key_enc, b.api_model, ts, ts});
  Bot out = b;
  out.id = sqlite3_last_insert_rowid(g_db);
  out.created_at = out.updated_at = ts;
  return out;
}

bool updateBot(const Bot& b) {
  std::lock_guard<std::recursive_mutex> lock(g_mtx);
  execute("UPDATE bots SET name=?,avatar=?,greeting=?,system_prompt=?,temperature=?,"
          "is_enabled=?,api_base_url=?,api_key_enc=?,api_model=?,updated_at=? WHERE id=?",
          {b.name, b.avatar, b.greeting, b.system_prompt,
           std::to_string(b.temperature), b.is_enabled ? "1" : "0",
           b.api_base_url, b.api_key_enc, b.api_model, nowIso(), std::to_string(b.id)});
  return sqlite3_changes(g_db) > 0;
}

bool deleteBot(int64_t id) {
  std::lock_guard<std::recursive_mutex> lock(g_mtx);
  auto def = getDefaultBot();   // recursive_mutex 可重入
  if (def && def->id == id) return false;
  execute("UPDATE sessions SET bot_id=0 WHERE bot_id=?", {std::to_string(id)});
  execute("DELETE FROM bots WHERE id=?", {std::to_string(id)});
  return true;
}

std::vector<Bot> listBots() {
  std::lock_guard<std::recursive_mutex> lock(g_mtx);
  std::vector<Bot> out;
  query("SELECT id,name,avatar,greeting,system_prompt,temperature,is_enabled,"
        "api_base_url,api_key_enc,api_model,created_at,updated_at "
        "FROM bots ORDER BY id ASC",
        {}, [&](sqlite3_stmt* st) { out.push_back(rowToBot(st)); });
  return out;
}

std::optional<Bot> getBot(int64_t id) {
  std::lock_guard<std::recursive_mutex> lock(g_mtx);
  std::optional<Bot> out;
  query("SELECT id,name,avatar,greeting,system_prompt,temperature,is_enabled,"
        "api_base_url,api_key_enc,api_model,created_at,updated_at "
        "FROM bots WHERE id=?",
        {std::to_string(id)},
        [&](sqlite3_stmt* st) { out = rowToBot(st); });
  return out;
}

bool setBotEnabled(int64_t id, bool enabled) {
  std::lock_guard<std::recursive_mutex> lock(g_mtx);
  execute("UPDATE bots SET is_enabled=?, updated_at=? WHERE id=?",
          {enabled ? "1" : "0", nowIso(), std::to_string(id)});
  return sqlite3_changes(g_db) > 0;
}

std::optional<Bot> getDefaultBot() {
  std::lock_guard<std::recursive_mutex> lock(g_mtx);
  auto idStr = getSetting("default_bot_id");
  if (idStr) {
    try {
      auto b = getBot(std::stoll(*idStr));
      if (b) return b;
    } catch (...) {
    }
  }
  std::optional<Bot> out;
  query("SELECT id,name,avatar,greeting,system_prompt,temperature,is_enabled,"
        "api_base_url,api_key_enc,api_model,created_at,updated_at "
        "FROM bots ORDER BY id ASC LIMIT 1",
        {}, [&](sqlite3_stmt* st) { out = rowToBot(st); });
  return out;
}
```

```cpp
  g.name = colText(st, 1);
  g.topic = colText(st, 2);
  g.status = colText(st, 3);
  g.created_at = colText(st, 4);

}

void setGroupMembers(int64_t groupId, const std::vector<int64_t>& botIds) {
  std::lock_guard<std::recursive_mutex> lock(g_mtx);
  execute("DELETE FROM group_members WHERE group_id=?", {std::to_string(groupId)});
  for (size_t i = 0; i < botIds.size(); ++i)
    execute("INSERT INTO group_members(group_id, bot_id, position) VALUES(?,?,?)",
            {std::to_string(groupId), std::to_string(botIds[i]), std::to_string(i)});

          {nowIso(), std::to_string(groupId)});
}

  std::vector<GroupMember> out;

        "WHERE group_id=? ORDER BY position ASC",
        {std::to_string(groupId)}, [&](sqlite3_stmt* st) {
          out.push_back({colInt(st, 0), colInt(st, 1), colInt(st, 2),
                         static_cast<int>(colInt(st, 3))});
        });
  return out;

GroupMessage appendGroupMessage(int64_t groupId, int64_t botId,
                                const std::string& role, const std::string& content) {
  std::lock_guard<std::recursive_mutex> lock(g_mtx);
  std::string ts = nowIso();
  sqlite3_stmt* st = nullptr;
  sqlite3_prepare_v2(g_db,
      "INSERT INTO group_messages(group_id, bot_id, role, content, created_at) "
      "VALUES(?,?,?,?,?)", -1, &st, nullptr);
  sqlite3_bind_int64(st, 1, groupId);
  if (botId > 0) sqlite3_bind_int64(st, 2, botId);
  else sqlite3_bind_null(st, 2);
  sqlite3_bind_text(st, 3, role.c_str(), -1, SQLITE_TRANSIENT);
  sqlite3_bind_text(st, 4, content.c_str(), -1, SQLITE_TRANSIENT);
  sqlite3_bind_text(st, 5, ts.c_str(), -1, SQLITE_TRANSIENT);
  sqlite3_step(st);
  sqlite3_finalize(st);
  execute("UPDATE groups SET updated_at=? WHERE id=?",
          {ts, std::to_string(groupId)});
  return {sqlite3_last_insert_rowid(g_db), groupId, botId, role, content, ts};
}

std::vector<GroupMessage> listGroupMessages(int64_t groupId, int limit) {
  std::lock_guard<std::recursive_mutex> lock(g_mtx);
  std::vector<GroupMessage> out;
  query("SELECT id, group_id, bot_id, role, content, created_at FROM group_messages "
        "WHERE group_id=? ORDER BY id ASC",
        {std::to_string(groupId)}, [&](sqlite3_stmt* st) {
          out.push_back({colInt(st, 0), colInt(st, 1), colInt(st, 2), colText(st, 3),
                         colText(st, 4), colText(st, 5)});
        });
  if (limit > 0 && out.size() > static_cast<size_t>(limit))
    out.erase(out.begin(), out.end() - limit);
  return out;
}
```

```cpp
// 注入式假流：前 failTimes 次调用直接发 error；onCall 可捕获请求上下文
struct FakeStream {
  std::vector<std::string> pieces = {"你好"};
  int failTimes = 0;
  std::atomic<int> calls{0};
  std::function<void()> onCall;
  std::mutex reqMtx;
  std::vector<llm::ChatMsg> lastMessages;

  void operator()(const llm::ChatRequest& req, llm::StreamCallback cb,
                  const std::atomic_bool& stop) {
    {
      std::lock_guard<std::mutex> lk(reqMtx);
      lastMessages = req.messages;
    }
    int n = calls.fetch_add(1) + 1;
    if (onCall) onCall();
    if (n <= failTimes) {
      cb({"error", "", 500, "模拟网络错误"});
      return;
    }
    for (auto& p : pieces) {
      if (stop) return;
      cb({"delta", p, 0, ""});
      std::this_thread::sleep_for(std::chrono::milliseconds(10));
    }
  }
};

// 广播收集器
struct Collector {
  std::mutex mtx;
  std::vector<std::pair<std::string, json>> events;
  void operator()(const std::string& event, const json& data) {
    std::lock_guard<std::mutex> lk(mtx);
    events.push_back({event, data});
  }
  int count(const std::string& ev) {
    std::lock_guard<std::mutex> lk(mtx);
    int n = 0;
    for (auto& [e, d] : events) if (e == ev) ++n;
    return n;
  }
  json last(const std::string& ev) {
    std::lock_guard<std::mutex> lk(mtx);
    for (auto it = events.rbegin(); it != events.rend(); ++it)
      if (it->first == ev) return it->second;
    return json();
  }
};

void waitUntil(const std::function<bool()>& cond, int timeoutMs = 5000) {
  auto deadline = std::chrono::steady_clock::now() + std::chrono::milliseconds(timeoutMs);
  while (std::chrono::steady_clock::now() < deadline) {
    if (cond()) return;
    std::this_thread::sleep_for(std::chrono::milliseconds(10));
  }
  REQUIRE(cond());
}
```

```cpp
#pragma once
#include <atomic>
#include <condition_variable>
#include <cstdint>
#include <functional>
#include <map>
#include <memory>
#include <mutex>
#include <string>
#include <thread>
#include <vector>

#include "json_util.h"
#include "llm_provider.h"

namespace grp {

using StreamFn = std::function<void(const llm::ChatRequest&, llm::StreamCallback,
                                    const std::atomic_bool&)>;
using Broadcaster = std::function<void(const std::string& event, const json& data)>;
using SubId = uint64_t;

// 每群一个实例：独立线程状态机 idle→running⇄paused→idle，SSE 广播给多订阅者。
// 生命周期：stop()/析构 join 线程；Registry 持有 shared_ptr 至群删除。
class GroupEngine {
 public:
  GroupEngine(int64_t groupId, StreamFn streamFn);
  ~GroupEngine();

  bool start();                       // idle→running；否则 false
  bool pause();                       // running→paused；否则 false
  bool resume();                      // paused→running；否则 false
  bool stop();                        // running/paused→idle（当前轮尽快中止）；已 idle 返回 false
  void interject(const std::string& content);   // 存 user 消息 + 广播

  std::string state() const;          // "idle" | "running" | "paused"
  int turn() const { return turn_.load(); }

  SubId subscribe(Broadcaster b);
  void unsubscribe(SubId id);

 private:
  enum class State { Idle, Running, Paused };
  struct Member {
    int64_t bot_id;
    std::string name;
    std::string avatar;
  };

  void loop();
  bool runTurn(const Member& m, int turn);   // 返回是否成功落库
  llm::ChatRequest buildRequest(const db::Bot& bot);
  void broadcast(const std::string& event, const json& data);

  int64_t groupId_;
  StreamFn streamFn_;
  std::vector<Member> members_;
  std::atomic<State> state_{State::Idle};
  std::atomic<int> turn_{0};
  std::atomic_bool stopFlag_{false};
  std::mutex pauseMtx_;
  std::condition_variable pauseCv_;
  std::thread thread_;
  std::map<int64_t, int> failCount_;   // 仅引擎线程访问
  std::mutex subMtx_;
  std::map<SubId, Broadcaster> subs_;
  SubId nextSubId_ = 0;
};

class GroupEngineRegistry {
 public:
  static GroupEngineRegistry& instance();

  std::shared_ptr<GroupEngine> getOrCreate(int64_t groupId, StreamFn streamFn);
  void remove(int64_t groupId);   // 若运行中先 stop（锁外 join）

 private:
  std::mutex mtx_;
  std::map<int64_t, std::shared_ptr<GroupEngine>> engines_;
};

}  // namespace grp
```

```cpp
#include "group_engine.h"

#include "db.h"
#include "dpapi_util.h"
#include "logger.h"

namespace grp {
namespace {

std::string stateName(GroupEngine&) = delete;  // 占位防止误用（实际用成员实现）
}  // namespace

GroupEngine::GroupEngine(int64_t groupId, StreamFn streamFn)
    : groupId_(groupId), streamFn_(std::move(streamFn)) {}

GroupEngine::~GroupEngine() {
  if (state_.load() != State::Idle) {
    stopFlag_ = true;
    state_ = State::Idle;
    pauseCv_.notify_all();
    if (thread_.joinable()) thread_.join();
  }
}

std::string GroupEngine::state() const {
  switch (state_.load()) {
    case State::Running: return "running";
    case State::Paused: return "paused";
    default: return "idle";
  }
}

bool GroupEngine::start() {
  State expected = State::Idle;
  if (!state_.compare_exchange_strong(expected, State::Running)) return false;
  members_.clear();
  for (auto& m : db::listGroupMembers(groupId_)) {
    auto bot = db::getBot(m.bot_id);
    if (bot) members_.push_back({m.bot_id, bot->name, bot->avatar});
  }
  if (members_.empty()) {
    state_ = State::Idle;
    db::setGroupStatus(groupId_, "idle");
    broadcast("error", {{"bot_id", 0}, {"name", ""}, {"message", "群内没有可用机器人"}});
    broadcast("status", {{"state", "idle"}, {"turn", 0}});
    return false;
  }
  turn_ = 0;
  stopFlag_ = false;
  failCount_.clear();
  db::setGroupStatus(groupId_, "running");
  broadcast("status", {{"state", "running"}, {"turn", 0}});
  thread_ = std::thread(&GroupEngine::loop, this);
  return true;
}

bool GroupEngine::pause() {
  State expected = State::Running;
  if (!state_.compare_exchange_strong(expected, State::Paused)) return false;
  db::setGroupStatus(groupId_, "paused");
  broadcast("status", {{"state", "paused"}, {"turn", turn_.load()}});
  return true;
}

bool GroupEngine::resume() {
  State expected = State::Paused;
  if (!state_.compare_exchange_strong(expected, State::Running)) return false;
  db::setGroupStatus(groupId_, "running");
  broadcast("status", {{"state", "running"}, {"turn", turn_.load()}});
  pauseCv_.notify_all();
  return true;
}

bool GroupEngine::stop() {
  State s = state_.load();
  if (s == State::Idle) return false;
  stopFlag_ = true;
  state_ = State::Idle;
  pauseCv_.notify_all();
  if (thread_.joinable()) thread_.join();
  db::setGroupStatus(groupId_, "idle");
  broadcast("status", {{"state", "idle"}, {"turn", turn_.load()}});
  return true;
}

void GroupEngine::interject(const std::string& content) {
  auto m = db::appendGroupMessage(groupId_, 0, "user", content);
  broadcast("interject", {{"id", m.id}, {"content", m.content},
                          {"created_at", m.created_at}});
}

SubId GroupEngine::subscribe(Broadcaster b) {
  std::lock_guard<std::mutex> lk(subMtx_);
  SubId id = ++nextSubId_;
  subs_[id] = std::move(b);
  return id;
}

void GroupEngine::unsubscribe(SubId id) {
  std::lock_guard<std::mutex> lk(subMtx_);
  subs_.erase(id);
}

void GroupEngine::broadcast(const std::string& event, const json& data) {
  std::vector<Broadcaster> copy;
  {
    std::lock_guard<std::mutex> lk(subMtx_);
    for (auto& [id, fn] : subs_) copy.push_back(fn);
  }
  for (auto& fn : copy) {
    try {
      fn(event, data);
    } catch (...) {
    }
  }
}

void GroupEngine::loop() {
  size_t idx = 0;
  int skipped = 0;   // 连续无成功落库的轮数（全员失败防空转）
  while (state_.load() == State::Running) {
    {
      std::unique_lock<std::mutex> lk(pauseMtx_);
      pauseCv_.wait(lk, [&] { return state_.load() != State::Paused; });
    }
    if (state_.load() != State::Running) break;
    const Member& m = members_[idx % members_.size()];
    int turn = turn_.fetch_add(1) + 1;
    bool ok = runTurn(m, turn);
    skipped = ok ? 0 : skipped + 1;
    if (skipped >= static_cast<int>(members_.size()) &&
        state_.load() == State::Running) {
      state_ = State::Paused;
      db::setGroupStatus(groupId_, "paused");
      broadcast("status", {{"state", "paused"}, {"turn", turn}});
      broadcast("error", {{"bot_id", 0}, {"name", ""},
                          {"message", "群内机器人全员连续失败，已自动暂停"}});
      break;
    }
    idx = (idx + 1) % members_.size();
  }
}

bool GroupEngine::runTurn(const Member& m, int turn) {
  broadcast("turn_start", {{"bot_id", m.bot_id}, {"name", m.name},
                           {"avatar", m.avatar}, {"turn", turn}});
  auto bot = db::getBot(m.bot_id);
  if (!bot) {
    broadcast("error", {{"bot_id", m.bot_id}, {"name", m.name},
                        {"message", "机器人不存在，跳过"}});
    return false;
  }
  if (!bot->is_enabled) {
    broadcast("error", {{"bot_id", m.bot_id}, {"name", m.name},
                        {"message", "机器人已停用，跳过"}});
    return false;
  }

  std::string full;
  std::string errMsg;
  bool failed = false;
  bool gotDelta = false;
  int attempts = 0;
  for (;;) {
    failed = false;
    errMsg.clear();
    llm::ChatRequest req = buildRequest(*bot);
    streamFn_(req,
              [&](const llm::StreamEvent& e) {
                if (stopFlag_) return;
                if (e.type == "delta") {
                  gotDelta = true;
                  full += e.content;
                  broadcast("delta", {{"bot_id", m.bot_id}, {"text", e.content}});
                } else if (e.type == "error") {
                  failed = true;
                  errMsg = e.message;
                }
              },
              stopFlag_);
    // 网络类失败（本轮无任何 delta）重试一次；已有内容的中断直接计失败
    if (!failed || gotDelta || attempts >= 1 || stopFlag_) break;
    ++attempts;
  }

  if (stopFlag_) return false;   // 被停止：不落库不广播
  if (failed) {
    failCount_[m.bot_id]++;
    broadcast("error", {{"bot_id", m.bot_id}, {"name", m.name},
                        {"message", errMsg.empty() ? "回复失败" : errMsg}});
    if (failCount_[m.bot_id] >= 3) {
      state_ = State::Paused;
      db::setGroupStatus(groupId_, "paused");
      broadcast("status", {{"state", "paused"}, {"turn", turn}});
    }
    return false;
  }
  failCount_[m.bot_id] = 0;
  if (full.empty()) full = "（无内容）";
  db::appendGroupMessage(groupId_, m.bot_id, "assistant", full);
  db::touchGroup(groupId_);
  broadcast("turn_end", {{"bot_id", m.bot_id}});
  return true;
}

llm::ChatRequest GroupEngine::buildRequest(const db::Bot& bot) {
  llm::ChatRequest req;
  req.temperature = bot.temperature;
  // API 覆盖：机器人字段非空则覆盖全局 settings
  req.base_url = !bot.api_base_url.empty()
                     ? bot.api_base_url
                     : db::getSetting("base_url").value_or("");
  std::string keyEnc = !bot.api_key_enc.empty()
                           ? bot.api_key_enc
                           : db::getSetting("api_key_enc").value_or("");
  if (!keyEnc.empty()) {
    try {
      req.api_key = dpapi::unprotect(keyEnc);
    } catch (const std::exception& e) {
      logx::error(std::string("group dpapi unprotect failed: ") + e.what());
    }
  }
  req.model = !bot.api_model.empty() ? bot.api_model
                                     : db::getSetting("model").value_or("");
  req.proxy_enabled = db::getSetting("proxy_enabled").value_or("0") == "1";
  req.proxy_host = db::getSetting("proxy_host").value_or("");
  try {
    req.proxy_port = std::stoi(db::getSetting("proxy_port").value_or("0"));
  } catch (...) {
    req.proxy_port = 0;
  }

  req.messages.push_back({"system", bot.system_prompt});
  auto group = db::getGroup(groupId_);
  if (group && !group->topic.empty())
    req.messages.push_back({"system", "当前群聊话题：" + group->topic});
  auto msgs = db::listGroupMessages(groupId_, 20);   // 最近 20 条
  for (auto& gm : msgs) {
    if (gm.bot_id == 0) {
      req.messages.push_back({"user", gm.content});
    } else {
      std::string name = "机器人";
      if (auto b = db::getBot(gm.bot_id)) name = b->name;
      req.messages.push_back({"assistant", "[" + name + "]：" + gm.content});
    }
  }
  return req;
}

GroupEngineRegistry& GroupEngineRegistry::instance() {
  static GroupEngineRegistry reg;
  return reg;
}

std::shared_ptr<GroupEngine> GroupEngineRegistry::getOrCreate(int64_t groupId,
                                                              StreamFn streamFn) {
  std::lock_guard<std::mutex> lk(mtx_);
  auto it = engines_.find(groupId);
  if (it != engines_.end()) return it->second;
  auto e = std::make_shared<GroupEngine>(groupId, std::move(streamFn));
  engines_[groupId] = e;
  return e;
}

void GroupEngineRegistry::remove(int64_t groupId) {
  std::shared_ptr<GroupEngine> e;
  {
    std::lock_guard<std::mutex> lk(mtx_);
    auto it = engines_.find(groupId);
    if (it == engines_.end()) return;
    e = it->second;
    engines_.erase(it);
  }
  e->stop();   // 锁外 join，避免阻塞其他 getOrCreate
}
```

```powershell
function Invoke-ExpectError($Method, $Uri, $Obj) {
  try {
    if ($null -eq $Obj) { Invoke-RestMethod $Uri -Method $Method | Out-Null }

    }
    throw
  }
```

```cpp
int64_t resolveDefaultBot() {
  auto id = db::getSetting("default_bot_id");
  if (id) {
    try {
      int64_t botId = std::stoll(*id);
      if (db::getBot(botId)) return botId;
    } catch (...) {
    }
  }
  auto bots = db::listBots();
  if (!bots.empty()) return bots.front().id;
  return 0;
}

std::string unprotectOrEmpty(const std::string& enc) {
  if (enc.empty()) return "";
  try {
    return dpapi::unprotect(enc);
  } catch (const std::exception& e) {
    logx::error(std::string("dpapi unprotect failed: ") + e.what());
    return "";
  }
}

struct BotConfig {
  std::string system_prompt;
  std::string base_url;
  std::string api_key;
  std::string model;
  double temperature = 0.8;
};

// 覆盖项为空 = 继承全局默认（settings）
BotConfig resolveBotConfig(const db::Bot& bot) {
  BotConfig cfg;
  cfg.system_prompt = bot.system_prompt;
  cfg.temperature = bot.temperature;
  cfg.base_url = bot.api_base_url;
  cfg.model = bot.api_model;
  cfg.api_key = unprotectOrEmpty(bot.api_key_enc);
  if (cfg.base_url.empty()) cfg.base_url = db::getSetting("base_url").value_or("");
  if (cfg.api_key.empty())
    cfg.api_key = unprotectOrEmpty(db::getSetting("api_key_enc").value_or(""));
  if (cfg.model.empty()) cfg.model = db::getSetting("model").value_or("");
  return cfg;
}

std::optional<db::Bot> botForSession(int64_t sessionId) {
  auto sess = db::getSession(sessionId);
  if (!sess) return std::nullopt;
  if (sess->bot_id > 0) {
    auto bot = db::getBot(sess->bot_id);
    if (bot) return bot;
  }
  int64_t def = resolveDefaultBot();
  if (def) return db::getBot(def);
  return std::nullopt;
}

// 校验群成员：2-10 个、须存在且启用
bool validateBotIds(const json& arr, std::vector<int64_t>& out,
                    std::string& err, int& errCode) {
  if (!arr.is_array() || arr.size() < 2 || arr.size() > 10) {
    err = "群成员需为 2-10 个机器人";
    errCode = 1003;
    return false;
  }
  for (auto& v : arr) {
    int64_t id = v.get<int64_t>();
    auto bot = db::getBot(id);
    if (!bot) {
      err = "机器人不存在: " + std::to_string(id);
      errCode = 404;
      return false;
    }
    if (!bot->is_enabled) {
      err = "机器人已停用: " + bot->name;
      errCode = 1004;
      return false;
    }
    out.push_back(id);
  }
  return true;
}

std::mutex g_stopMtx;
std::map<int64_t, std::shared_ptr<std::atomic_bool>> g_stopFlags;

int64_t parseSessionId(const httplib::Request& req, httplib::Response& res) {
  json b = parseBody(req, res);
  if (res.status == 400) return 0;
  int64_t sid = b.value("session_id", (int64_t)0);
  if (!sid) {
    fail(res, 400, 400, "缺少 session_id");
    return 0;
  }
  return sid;
}

void runChat(int64_t sessionId, const std::string& content, bool appendUser,
             httplib::Response& res) {
  if (!db::getSession(sessionId)) {
    fail(res, 404, 404, "会话不存在");
    return;
  }
  auto bot = botForSession(sessionId);
  if (!bot || bot->system_prompt.empty()) {
    fail(res, 500, 500, "没有可用机器人");
    return;
  }
  BotConfig cfg = resolveBotConfig(*bot);
  int keep = 20;
  try {
    keep = std::stoi(db::getSetting("keep_rounds").value_or("20"));
  } catch (...) {
  }
  int proxyPort = 0;
  try {
    proxyPort = std::stoi(db::getSetting("proxy_port").value_or("0"));
  } catch (...) {
  }

  // 先组装上下文再落库，避免 user 消息在 LLM 上下文中重复出现
  auto history = db::listMessages(sessionId);
  auto ctx = chat::buildContext(cfg.system_prompt, history, keep,
                                appendUser ? content : "");

  if (appendUser) {
    auto sess = db::getSession(sessionId);
    if (sess && sess->title == "新对话") db::renameSession(sessionId, utf8Truncate(content, 20));
    db::appendMessage(sessionId, "user", content);
    db::touchSession(sessionId);
  }

  llm::ChatRequest req;
  req.messages = ctx;
  req.temperature = cfg.temperature;
  req.base_url = cfg.base_url;
  req.api_key = cfg.api_key;
  req.model = cfg.model;
  req.proxy_enabled = db::getSetting("proxy_enabled").value_or("0") == "1";
  req.proxy_host = db::getSetting("proxy_host").value_or("");
  req.proxy_port = proxyPort;

  auto stop = std::make_shared<std::atomic_bool>(false);
  {
    std::lock_guard<std::mutex> lk(g_stopMtx);
    g_stopFlags[sessionId] = stop;
  }

  auto full = std::make_shared<std::string>();
  auto hadError = std::make_shared<bool>(false);
  auto errCode = std::make_shared<int>(0);
  auto errMsg = std::make_shared<std::string>();

  res.set_header("Cache-Control", "no-cache");
  res.set_chunked_content_provider(
      "text/event-stream",
      [req, sessionId, stop, full, hadError, errCode, errMsg](size_t,
                                                             httplib::DataSink& sink) {
        try {
          llm::OpenAiCompatProvider provider;
          provider.streamChat(
              req,
              [&](const llm::StreamEvent& e) {
                if (!sink.is_writable()) {
                  stop->store(true);
                  return;
                }
                if (e.type == "delta") {
                  *full += e.content;
                  json j = {{"content", e.content}};
                  std::string sse = "event: delta\ndata: " + j.dump() + "\n\n";
                  sink.write(sse.data(), sse.size());
                } else if (e.type == "error") {
                  *hadError = true;
                  *errCode = e.error_code;
                  *errMsg = e.message;
                  json j = {{"code", e.error_code}, {"message", e.message}};
                  std::string sse = "event: error\ndata: " + j.dump() + "\n\n";
                  sink.write(sse.data(), sse.size());
                }
              },
              *stop);
          {
            std::lock_guard<std::mutex> lk(g_stopMtx);
            g_stopFlags.erase(sessionId);
          }
          if (!*hadError && !full->empty()) {
            db::appendMessage(sessionId, "assistant", *full);
            db::touchSession(sessionId);
            ev::EventBus::instance().emit(
                "chat.completed",
                {{"session_id", sessionId}, {"length", full->size()}});
          } else if (*hadError) {
            ev::EventBus::instance().emit(
                "chat.error", {{"session_id", sessionId},
                               {"code", *errCode},
                               {"message", *errMsg}});
          }
        } catch (const std::exception& e) {
          logx::error(std::string("chat stream failed: ") + e.what());
          if (sink.is_writable()) {
            json j = {{"code", 500}, {"message", std::string("服务内部错误: ") + e.what()}};
            std::string sse = "event: error\ndata: " + j.dump() + "\n\n";
            sink.write(sse.data(), sse.size());
          }
        }
        if (sink.is_writable()) {
          json done = {{"session_id", sessionId}};
          std::string sse = "event: done\ndata: " + done.dump() + "\n\n";
          sink.write(sse.data(), sse.size());
        }
        sink.done();
        return true;
      });
}

void registerChatRoutes(httplib::Server& svr) {
  // 与 v1 完全一致：POST /api/v1/chat/stream、/regenerate、/stop（原样保留）
  logx::info("registering chat routes");
  svr.Post("/api/v1/chat/stream", [](const httplib::Request& req, httplib::Response& res) {
    json b = parseBody(req, res);
    if (res.status == 400) return;
    int64_t sid = b.value("session_id", (int64_t)0);
    std::string content = b.value("content", "");
    if (!sid) {
      fail(res, 400, 400, "缺少 session_id");
      return;
    }
    if (content.empty()) {
      fail(res, 400, 400, "消息内容为空");
      return;
    }
    runChat(sid, content, true, res);
  });

  svr.Post("/api/v1/chat/regenerate", [](const httplib::Request& req, httplib::Response& res) {
    int64_t sid = parseSessionId(req, res);
    if (!sid) return;
    auto lastU = db::lastMessageByRole(sid, "user");
    if (!lastU) {
      fail(res, 400, 400, "没有可重新生成的消息");
      return;
    }
    auto lastA = db::lastMessageByRole(sid, "assistant");
    if (lastA) db::deleteMessage(lastA->id);
    runChat(sid, "", false, res);
  });

  svr.Post("/api/v1/chat/stop", [](const httplib::Request& req, httplib::Response& res) {
    int64_t sid = parseSessionId(req, res);
    if (!sid) return;
    {
      std::lock_guard<std::mutex> lk(g_stopMtx);
      auto it = g_stopFlags.find(sid);
      if (it != g_stopFlags.end()) it->second->store(true);
    }
    res.set_content(okJson(json{{"stopped", true}}).dump(), "application/json; charset=utf-8");
  });
}

    auto g = db::getGroup(id);
    if (!g) {

    }
    auto engine = grp::GroupEngineRegistry::instance().getOrCreate(id, engineStreamFn());
    if (b.contains("bot_ids") && engine->state() != "idle") {

    }
    db::updateGroup(id, b.value("name", g->name), b.value("topic", g->topic));
    if (b.contains("bot_ids")) {
      std::vector<int64_t> ids;
      std::string err;
      int errCode = 0;
      if (!validateBotIds(b["bot_ids"], ids, err, errCode)) {

  svr.Delete(R"(/api/v1/groups/(\d+))", [](const httplib::Request& req, httplib::Response& res) {

  svr.Get(R"(/api/v1/groups/(\d+)/messages)", [](const httplib::Request& req, httplib::Response& res) {

    res.set_content(okJson(arr).dump(), "application/json; charset=utf-8");
  });

  // 控制端点共享实现
  auto ctrl = [](const httplib::Request& req, httplib::Response& res, const std::string& op) {
    int64_t id = std::stoll(req.matches[1].str());
    if (!db::getGroup(id)) {
      fail(res, 404, 404, "群不存在");
      return;
    }
    auto engine = grp::GroupEngineRegistry::instance().getOrCreate(id, engineStreamFn());
    if (op == "start") {
      json b = parseBody(req, res);
      if (res.status == 400) return;
      std::string topic = b.value("topic", "");
      auto g = db::getGroup(id);
      if (!topic.empty()) db::updateGroup(id, g->name, topic);
      if (engine->state() != "idle") {
        fail(res, 409, 1002, "群聊已在进行中");
        return;
      }
      if (!engine->start()) {
        fail(res, 409, 1002, "群内没有可用机器人");
        return;
      }
    } else if (op == "pause") {
      if (!engine->pause()) {
        fail(res, 409, 1002, "当前不在运行状态");
        return;
      }
    } else if (op == "resume") {
      if (!engine->resume()) {
        fail(res, 409, 1002, "当前不在暂停状态");
        return;
      }
    } else if (op == "stop") {
      engine->stop();  // 幂等，任意状态可调
    } else if (op == "interject") {
      json b = parseBody(req, res);
      if (res.status == 400) return;
      std::string content = b.value("content", "");
      if (content.empty()) {
        fail(res, 400, 400, "插话内容为空");
        return;
      }
      engine->interject(content);
    }
    res.set_content(okJson(json{{"state", engine->state()}}).dump(),
                    "application/json; charset=utf-8");
  };
  svr.Post(R"(/api/v1/groups/(\d+)/start)", [ctrl](const httplib::Request& req, httplib::Response& res) { ctrl(req, res, "start"); });
  svr.Post(R"(/api/v1/groups/(\d+)/pause)", [ctrl](const httplib::Request& req, httplib::Response& res) { ctrl(req, res, "pause"); });
  svr.Post(R"(/api/v1/groups/(\d+)/resume)", [ctrl](const httplib::Request& req, httplib::Response& res) { ctrl(req, res, "resume"); });
  svr.Post(R"(/api/v1/groups/(\d+)/stop)", [ctrl](const httplib::Request& req, httplib::Response& res) { ctrl(req, res, "stop"); });
  svr.Post(R"(/api/v1/groups/(\d+)/interject)", [ctrl](const httplib::Request& req, httplib::Response& res) { ctrl(req, res, "interject"); });

  // 群流 SSE：多客户端各自订阅，事件经每订阅者独立队列转发
  svr.Get(R"(/api/v1/groups/(\d+)/stream)", [](const httplib::Request& req, httplib::Response& res) {
    int64_t id = std::stoll(req.matches[1].str());
    auto engine = grp::GroupEngineRegistry::instance().getOrCreate(id, engineStreamFn());
    struct SubState {
      std::mutex mtx;
      std::condition_variable cv;
      std::deque<std::string> events;
    };
    auto st = std::make_shared<SubState>();
    grp::SubId sub = engine->subscribe([st](const std::string& event, const json& data) {
      {
        std::lock_guard<std::mutex> lk(st->mtx);
        st->events.push_back("event: " + event + "\ndata: " + data.dump() + "\n\n");
      }
      st->cv.notify_all();
    });
    // 初始 status：客户端立刻拿到当前状态与轮数
    st->events.push_back(
        "event: status\ndata: " +
        json{{"state", engine->state()}, {"turn", engine->turn()}}.dump() + "\n\n");

    res.set_header("Cache-Control", "no-cache");
    res.set_chunked_content_provider(
        "text/event-stream",
        [engine, sub, st](size_t, httplib::DataSink& sink) {
          for (;;) {
            if (!sink.is_writable()) break;
            std::string sse;
            {
              std::unique_lock<std::mutex> lk(st->mtx);
              st->cv.wait_for(lk, std::chrono::milliseconds(500),
                              [&] { return !st->events.empty(); });
              if (!st->events.empty()) {
                sse = st->events.front();
                st->events.pop_front();
              }
            }
            if (sse.empty()) continue;
            if (!sink.is_writable()) break;
            sink.write(sse.data(), sse.size());
          }
          engine->unsubscribe(sub);
          sink.done();
          return true;
        });
  });
}

/* ---------- 导出路由（与 v1 完全一致，原样保留） ---------- */

void registerExportRoute(httplib::Server& svr) {
  svr.Post("/api/v1/export", [](const httplib::Request& req, httplib::Response& res) {
    int64_t sid = req.has_param("session_id") ? std::stoll(req.get_param_value("session_id")) : 0;
    std::string fmt = req.has_param("format") ? req.get_param_value("format") : "md";
    if (!sid) {
      fail(res, 400, 400, "缺少 session_id");
      return;
    }
    auto sess = db::getSession(sid);
    if (!sess) {
      fail(res, 404, 404, "会话不存在");
      return;
    }
    auto msgs = db::listMessages(sid);

    std::string body, mime, ext;
    if (fmt == "json") {
      mime = "application/json; charset=utf-8";
      ext = "json";
      json arr = json::array();
      for (auto& m : msgs)
        arr.push_back({{"role", m.role}, {"content", m.content}, {"created_at", m.created_at}});
      body = json{{"title", sess->title}, {"exported_at", nowIso()}, {"messages", arr}}.dump(2);
    } else if (fmt == "txt") {
      mime = "text/plain; charset=utf-8";
      ext = "txt";
      body = "会话：" + sess->title + "\n导出时间：" + nowIso() + "\n\n";
      for (auto& m : msgs) {
        std::string who = m.role == "user" ? "用户" : (m.role == "assistant" ? "AI" : "系统");
        body += "[" + who + "] " + m.created_at + "\n" + m.content + "\n\n";
      }
    } else {
      mime = "text/markdown; charset=utf-8";
      ext = "md";
      body = "# " + sess->title + "\n\n> 导出时间：" + nowIso() + "\n\n";
      for (auto& m : msgs) {
        std::string who = m.role == "user" ? "**用户**" : (m.role == "assistant" ? "**AI**" : "**系统**");
        body += who + "（" + m.created_at + "）\n\n" + m.content + "\n\n---\n\n";
      }
    }
    std::string fname = "session_" + std::to_string(sid) + "_" + std::to_string(std::time(nullptr)) + "." + ext;
    res.set_header("Content-Disposition", "attachment; filename=\"" + fname + "\"");
    res.set_content(body, mime);
  });
}

void registerRoutes(httplib::Server& svr, const std::string& staticDir) {
  svr.set_pre_routing_handler([](const httplib::Request& req, httplib::Response& res) {
    std::string origin = req.get_header_value("Origin");
    bool allowed = origin == "https://app.local" ||
                   origin.rfind("http://localhost:", 0) == 0 ||
                   origin.rfind("http://127.0.0.1:", 0) == 0;
    if (allowed) {
      res.set_header("Access-Control-Allow-Origin", origin);
      res.set_header("Access-Control-Allow-Methods", "GET, POST, PUT, PATCH, DELETE, OPTIONS");
      res.set_header("Access-Control-Allow-Headers", "Content-Type");
    }
    if (req.method == "OPTIONS") {
      res.status = 204;
      return httplib::Server::HandlerResponse::Handled;
    }
    return httplib::Server::HandlerResponse::Unhandled;
  });

  svr.Get("/health", [](const httplib::Request&, httplib::Response& res) {
    res.set_content("{\"status\":\"ok\",\"version\":\"2.0.0\"}", "application/json; charset=utf-8");
  });

  registerConfigRoutes(svr);
  registerBotRoutes(svr);
  registerGroupRoutes(svr);
  registerSessionRoutes(svr);
  registerMessageRoutes(svr);
  registerExportRoute(svr);
  registerChatRoutes(svr);

  svr.set_error_handler([](const httplib::Request&, httplib::Response& res) {
    if (res.body.empty() && res.status == 404) {
      res.set_content(errJson(404, "接口不存在").dump(), "application/json; charset=utf-8");
      return httplib::Server::HandlerResponse::Handled;
    }
    return httplib::Server::HandlerResponse::Unhandled;
  });

  svr.set_exception_handler([](const httplib::Request&, httplib::Response& res,
                               std::exception_ptr ep) {
    std::string msg = "未知异常";
    try {
      if (ep) std::rethrow_exception(ep);
    } catch (const std::exception& e) {
      msg = e.what();
    } catch (...) {
    }
    logx::error(std::string("handler exception: ") + msg);
    res.status = 500;
    res.set_content(errJson(500, "服务内部错误").dump(), "application/json; charset=utf-8");
  });

  if (!staticDir.empty()) {
    svr.set_mount_point("/", staticDir);
    svr.set_file_extension_and_mimetype_mapping("css", "text/css");
    svr.set_file_extension_and_mimetype_mapping("js", "text/javascript");
    svr.set_file_extension_and_mimetype_mapping("html", "text/html");
    svr.set_file_extension_and_mimetype_mapping("json", "application/json; charset=utf-8");
    svr.set_file_extension_and_mimetype_mapping("png", "image/png");
    svr.set_file_extension_and_mimetype_mapping("svg", "image/svg+xml");
    svr.set_file_extension_and_mimetype_mapping("woff2", "font/woff2");
    logx::info("static file serving enabled: " + staticDir);
  }
}
```

```javascript
class Typewriter {
  constructor(el, onDrain) {
    this.el = el;
    this.buf = '';
    this.timer = null;
    this.onDrain = onDrain;
  }
  push(text) { this.buf += text; this.flush(); }
  flush() {
    if (this.timer || !this.buf) return;
    this.timer = setInterval(() => {
      if (!this.buf) {
        clearInterval(this.timer);
        this.timer = null;
        if (this.onDrain) this.onDrain();
        return;
      }
      this.el.textContent += this.buf.slice(0, 4);
      this.buf = this.buf.slice(4);
    }, 24);
  }
  finish() {
    if (this.buf) this.el.textContent += this.buf;
    this.buf = '';
    if (this.timer) { clearInterval(this.timer); this.timer = null; }
    if (this.onDrain) this.onDrain();
  }
}

async function consumeSse(url, body, handlers) {
  const ctrl = new AbortController();
  App.state.abortCtrl = ctrl;
  try {
    const res = await fetch(url, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(body),
      signal: ctrl.signal,
    });
    if (!res.ok || !res.body) {
      const err = await res.json().catch(() => ({}));
      throw new Error(err.message || `HTTP ${res.status}`);
    }
    const reader = res.body.getReader();
    const dec = new TextDecoder();
    let buf = '';
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      buf += dec.decode(value, { stream: true });
      let idx;
      while ((idx = buf.indexOf('\n\n')) >= 0) {
        const block = buf.slice(0, idx);
        buf = buf.slice(idx + 2);
        let ev = 'message', data = '';
        for (const line of block.split('\n')) {
          if (line.startsWith('event: ')) ev = line.slice(7).trim();
          else if (line.startsWith('data: ')) data += line.slice(6);
        }
        if (!data) continue;
        let obj;
        try { obj = JSON.parse(data); } catch (_) { continue; }
        if (ev === 'delta') handlers.onDelta && handlers.onDelta(obj.content || '');
        else if (ev === 'done') handlers.onDone && handlers.onDone(obj);
        else if (ev === 'error') {
          const e = new Error(obj.message || '生成失败');
          e.code = obj.code;
          handlers.onError && handlers.onError(e);
        }
      }
    }
  } catch (e) {
    if (e.name === 'AbortError') return;
    handlers.onError && handlers.onError(e);
  }
}

function metaBar(role, msgId) {
  let btns = '<button data-action="copy" title="复制">📋</button>';
  if (role === 'assistant') btns += '<button data-action="regenerate" title="重新生成">🔄</button>';
  if (msgId) btns += '<button data-action="delete" title="删除">🗑</button>';
  return `<div class="msg-meta">${btns}</div>`;
}

function botNameForSession() {
  const s = App.state.sessions.find((x) => x.id === App.state.currentSessionId);
  if (s && s.bot_id > 0) {
    const b = App.state.bots.find((x) => x.id === s.bot_id);
    if (b) return b.name;
  }
  return 'AI';
}

function addBubble(role, text, opts = {}) {
  const bubble = document.createElement('div');
  bubble.className = 'msg ' + (role === 'user' ? 'msg-user' : 'msg-ai');
  if (opts.id) bubble.dataset.msgId = opts.id;
  const who = role === 'user' ? '我' : botNameForSession();
  bubble.innerHTML = `
    <div class="msg-who">${escapeHtml(who)}</div>
    <div class="msg-content">${opts.streaming ? '' : renderMarkdown(text)}</div>
    ${opts.streaming ? '' : metaBar(role, opts.id)}`;
  messagesEl.appendChild(bubble);
  const contentEl = bubble.querySelector('.msg-content');
  if (!opts.streaming) highlightCode(contentEl);
  return {
    el: bubble,
    contentEl,
    finalize(full) {
      contentEl.innerHTML = renderMarkdown(full);
      highlightCode(contentEl);
      if (!bubble.querySelector('.msg-meta')) bubble.insertAdjacentHTML('beforeend', metaBar(role));
      scrollToBottom();
    },
    showError(msg) {
      contentEl.innerHTML = `<span class="msg-error">⚠ ${escapeHtml(msg)}</span>`;
    },
  };
}

function setStreamingUI(streaming) {
  App.state.streaming = streaming;
  $('btn-send').classList.toggle('hidden', streaming);
  $('btn-stop').classList.toggle('hidden', !streaming);
  $('stream-hint').classList.toggle('hidden', !streaming);
}

/* ================= 会话 ================= */
async function refreshSessions() {
  App.state.sessions = await App.api.get('/api/v1/sessions');
  renderSessions();
}

function renderSessions() {
  const el = $('session-list');
  const q = App.state.search.trim().toLowerCase();
  const list = App.state.sessions.filter((s) => !q || s.title.toLowerCase().includes(q));
  el.innerHTML = '';
  for (const s of list) {
    const item = document.createElement('div');
    item.className = 'list-item' + (s.id === App.state.currentSessionId ? ' active' : '');
    item.innerHTML = `<div class="list-item-title">${escapeHtml(s.title)}</div>`;
    item.onclick = () => App.run('select-session', s.id);
    item.ondblclick = () => App.run('rename-session', s.id);
    const del = document.createElement('button');
    del.className = 'list-item-btn';
    del.textContent = '🗑';
    del.title = '删除会话';
    del.onclick = (e) => { e.stopPropagation(); App.run('delete-session', s.id); };
    item.appendChild(del);
    el.appendChild(item);
  }
}

function updateChatSub(sid) {
  const s = App.state.sessions.find((x) => x.id === sid);
  if (!s) { $('chat-sub').textContent = ''; return; }
  if (s.bot_id > 0) {
    const b = App.state.bots.find((x) => x.id === s.bot_id);
    $('chat-sub').textContent = b ? `与 ${b.name} 对话` : '与默认机器人对话';
  } else {
    $('chat-sub').textContent = '与默认机器人对话';
  }
}

async function loadMessages(sid) {
  const msgs = await App.api.get(`/api/v1/messages?session_id=${sid}&limit=100`);
  messagesEl.innerHTML = '';
  for (const m of [...msgs].reverse()) {
    if (m.role === 'user') addBubble('user', m.content, { id: m.id });
    else if (m.role === 'assistant') addBubble('assistant', m.content, { id: m.id });
    else {
      const note = document.createElement('div');
      note.className = 'sysnote';
      note.textContent = m.content;
      messagesEl.appendChild(note);
    }
  }
  scrollToBottom();
}

App.registerCommand('select-session', async (id) => {
  App.state.currentSessionId = id;
  renderSessions();
  const s = App.state.sessions.find((x) => x.id === id);
  $('chat-title').textContent = s ? s.title : '新对话';
  updateChatSub(id);
  await loadMessages(id);
  $('chat-empty').classList.add('hidden');
  $('messages').classList.remove('hidden');
  $('composer').classList.remove('hidden');
  $('btn-switch-bot').classList.remove('hidden');
});

App.registerCommand('rename-session', async (id) => {
  const s = App.state.sessions.find((x) => x.id === id);
  if (!s) return;
  const title = await promptText('重命名会话', s.title);
  if (!title) return;
  await App.api.patch(`/api/v1/sessions/${id}`, { title });
  await refreshSessions();
  if (App.state.currentSessionId === id) $('chat-title').textContent = title;
});

App.registerCommand('delete-session', async (id) => {

    App.state.currentSessionId = null;

    $('chat-title').textContent = '新对话';
    $('chat-sub').textContent = '';
    $('messages').classList.add('hidden');

    $('chat-empty').classList.remove('hidden');
  }
  await refreshSessions();
});

App.registerCommand('save-new-session', async () => {
  const checked = $('ns-bots').querySelector('input:checked');
  if (!checked) { toast('请选择一个机器人'); return; }
  const botId = Number(checked.value);
  const mode = $('modal-new-session').dataset.mode;
  $('modal-new-session').classList.add('hidden');
  if (mode === 'switch') {
    const sid = App.state.currentSessionId;

    updateChatSub(sid);
    toast('已切换机器人');
  } else {
    const s = await App.api.post('/api/v1/sessions', { bot_id: botId });
    await refreshSessions();
    App.run('select-session', s.id);
  }
});

App.registerCommand('send-message', async () => {
  const sid = App.state.currentSessionId;
  const content = inputEl.value.trim();
  if (!sid || !content || App.state.streaming) return;
  inputEl.value = '';
  setStreamingUI(true);
  addBubble('user', content);
  scrollToBottom();
  const bubble = addBubble('assistant', '', { streaming: true });
  let full = '';
  const tw = new Typewriter(bubble.contentEl, () => { bubble.finalize(full); });
  try {
    await consumeSse('/api/v1/chat/stream', { session_id: sid, content }, {
      onDelta: (d) => { full += d; tw.push(d); scrollToBottom(); },
      onDone: () => { tw.finish(); App.run('refresh-after-chat'); },
      onError: (e) => {
        tw.finish();
        bubble.showError(e.message || '生成失败');
        App.run('refresh-after-chat');
      },
    });
  } catch (e) {
    tw.finish();
    bubble.showError(e.message);
    App.run('refresh-after-chat');
  }
});

App.registerCommand('refresh-after-chat', async () => {
  setStreamingUI(false);
  await refreshSessions(true);
  if (App.state.currentSessionId) loadMessages(App.state.currentSessionId);
});

App.registerCommand('stop-stream', async () => {
  if (!App.state.streaming) return;
  const sid = App.state.currentSessionId;
  try { App.state.abortCtrl?.abort(); } catch (_) {}
  if (sid) App.api.post('/api/v1/chat/stop', { session_id: sid }).catch(() => {});
  App.run('refresh-after-chat');
});

App.registerCommand('regenerate', async () => {
  if (App.state.streaming) { toast('正在生成中…'); return; }
  const sid = App.state.currentSessionId;
  if (!sid) return;
  setStreamingUI(true);
  const bubble = addBubble('assistant', '', { streaming: true });
  let full = '';
  const tw = new Typewriter(bubble.contentEl, () => { bubble.finalize(full); });
  try {
    await consumeSse('/api/v1/chat/regenerate', { session_id: sid }, {
      onDelta: (d) => { full += d; tw.push(d); scrollToBottom(); },
      onDone: () => { tw.finish(); App.run('refresh-after-chat'); },
      onError: (e) => { tw.finish(); bubble.showError(e.message || '生成失败'); App.run('refresh-after-chat'); },
    });
  } catch (e) {
    tw.finish();
    bubble.showError(e.message);
    App.run('refresh-after-chat');
  }
});

App.registerCommand('export-session', async () => {
  const sid = App.state.currentSessionId;
  if (!sid) { toast('请先选择会话'); return; }
  const fmt = await promptText('导出格式（md / json / txt）', 'md');
  if (!['md', 'json', 'txt'].includes(fmt)) return;
  const res = await fetch(`${API_BASE}/api/v1/export?session_id=${sid}&format=${fmt}`, { method: 'POST' });
  if (!res.ok) { toast('导出失败'); return; }
  const blob = await res.blob();
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = `chat_${sid}.${fmt}`;
  a.click();
  URL.revokeObjectURL(a.href);
});

  const data = await App.api.get('/api/v1/bots');

function renderBots() {
  const el = $('bot-list');
  const q = App.state.search.trim().toLowerCase();
  const list = App.state.bots.filter((b) => !q || b.name.toLowerCase().includes(q));
  el.innerHTML = '';
  $('bots-empty').classList.toggle('hidden', list.length > 0);
  for (const b of list) {

    item.innerHTML = `

App.registerCommand('save-bot', async () => {
  const name = $('be-name').value.trim();
  const prompt = $('be-prompt').value.trim();
  if (!name || !prompt) { toast('名称与 System Prompt 不能为空'); return; }
  const body = {
    name,
    avatar: $('be-avatar').value.trim() || '🤖',
    greeting: $('be-greeting').value.trim(),

  $('modal-bot').classList.add('hidden');

});

// 按 gmsg id 去重（SSE 与 REST 重建可能重复投递同一条）
function addGroupBubbleChecked(botId, name, avatar, text, opts = {}) {
  if (opts.id && App.state.gmsgSeen.has(opts.id)) return null;
  if (opts.id) App.state.gmsgSeen.add(opts.id);
  return addGroupBubble(botId, name, avatar, text, opts);
}

function addGroupNote(text) {
  const note = document.createElement('div');
  note.className = 'sysnote';
  note.textContent = text;
  $('group-messages').appendChild(note);
  scrollGroupToBottom();
}

App.registerCommand('open-group-room', async (gid) => {
  closeGroupStream();
  App.state.typers.clear();
  App.state.gmsgSeen.clear();
  App.state.currentGroupId = gid;
  App.state.groupStatus = 'idle';
  App.state.groupTurn = 0;
  App.state.groupBackoff = 1000;
  let g;
  try {
    g = await App.api.get(`/api/v1/groups/${gid}`);
  } catch (e) {
    App.state.currentGroupId = null;
    toast(e.message);
    return;
  }
  App.state.currentGroup = g;
  $('group-empty').classList.add('hidden');
  $('group-room').classList.remove('hidden');
  $('group-title').textContent = g.name;
  $('group-sub').textContent = g.topic ? `话题：${g.topic}` : '';
  $('group-topic').value = '';
  App.state.groupStatus = g.status;
  App.state.groupTurn = 0;
  updateGroupControls();
  await reconcileGroupMessages();
  openGroupStream(gid);
});

App.registerCommand('close-group-room', () => {
  if (App.state.currentGroupId === null) return;
  closeGroupStream();
  App.state.typers.clear();
  App.state.currentGroupId = null;
  App.state.currentGroup = null;
  $('group-room').classList.add('hidden');
  $('group-empty').classList.remove('hidden');
  renderGroups();
});

function closeGroupStream() {
  try { App.state.groupAbort?.abort(); } catch (_) {}
  App.state.groupAbort = null;
  clearTimeout(App.state.groupReconnectTimer);
  App.state.groupReconnectTimer = null;
}

// 以 REST 为准全量重建消息区（turn_end 时引擎已落库，此时无在途打字机）
async function reconcileGroupMessages() {
  const gid = App.state.currentGroupId;
  if (!gid) return;
  try {
    const msgs = await App.api.get(`/api/v1/groups/${gid}/messages?limit=200`);
    const el = $('group-messages');
    el.innerHTML = '';
    for (const m of [...msgs].reverse()) {
      addGroupBubbleChecked(m.bot_id, m.name, m.avatar, m.content, { id: m.id });
    }
    scrollGroupToBottom();
  } catch (_) {}
}

function updateGroupControls() {
  const st = App.state.groupStatus;
  $('btn-group-start').classList.toggle('hidden', st !== 'idle');
  $('btn-group-pause').classList.toggle('hidden', st !== 'running');
  $('btn-group-resume').classList.toggle('hidden', st !== 'paused');
  $('btn-group-stop').classList.toggle('hidden', st === 'idle');
  $('group-turn').classList.toggle('hidden', st === 'idle');
  if (st !== 'idle') $('group-turn').textContent = `第 ${App.state.groupTurn} 轮`;
}

function ensureTyper(obj) {
  const key = obj.bot_id;
  let t = App.state.typers.get(key);
  if (!t) {
    const b = addGroupBubble(key, obj.name || '机器人', obj.avatar || '🤖', '', { streaming: true });
    const tw = new Typewriter(b.contentEl, () => {});
    t = { bubble: b, tw, full: '' };
    App.state.typers.set(key, t);
  }
  return t;
}

function finishTyper(botId) {
  const t = App.state.typers.get(botId);
  if (!t) return;
  App.state.typers.delete(botId);
  t.tw.finish();
  t.bubble.finalize(t.full);
  reconcileGroupMessages();
}

function handleGroupEvent(ev, obj) {
  if (ev === 'status') {
    const prev = App.state.groupStatus;
    App.state.groupStatus = obj.state;
    App.state.groupTurn = obj.turn || App.state.groupTurn;
    updateGroupControls();
    if (obj.state === 'idle' && prev !== 'idle') addGroupNote('群聊已停止');
  } else if (ev === 'turn_start') {
    ensureTyper(obj);
  } else if (ev === 'delta') {
    const t = ensureTyper(obj);
    t.full += obj.text || '';
    t.tw.push(obj.text || '');
    scrollGroupToBottom();
  } else if (ev === 'turn_end') {
    finishTyper(obj.bot_id);
  } else if (ev === 'interject') {
    addGroupBubbleChecked(0, '用户', '🙋', obj.content, { id: obj.id });
    scrollGroupToBottom();
  } else if (ev === 'error') {
    finishTyper(obj.bot_id);
    addGroupNote(`⚠ ${obj.name || '机器人'} 回复失败：${obj.message || ''}`);
  }
}

async function openGroupStream(gid) {
  closeGroupStream();
  const ctrl = new AbortController();
  App.state.groupAbort = ctrl;
  try {
    const res = await fetch(`${API_BASE}/api/v1/groups/${gid}/stream`, { signal: ctrl.signal });
    if (!res.ok || !res.body) {
      const err = await res.json().catch(() => ({}));
      throw new Error(err.message || `HTTP ${res.status}`);
    }
    App.state.groupBackoff = 1000;
    setBanner('');
    const reader = res.body.getReader();
    const dec = new TextDecoder();
    let buf = '';
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      buf += dec.decode(value, { stream: true });
      let idx;
      while ((idx = buf.indexOf('\n\n')) >= 0) {
        const block = buf.slice(0, idx);
        buf = buf.slice(idx + 2);
        let ev = 'message', data = '';
        for (const line of block.split('\n')) {
          if (line.startsWith('event: ')) ev = line.slice(7).trim();
          else if (line.startsWith('data: ')) data += line.slice(6);
        }
        if (!data) continue;
        let obj;
        try { obj = JSON.parse(data); } catch (_) { continue; }
        handleGroupEvent(ev, obj);
      }
    }
  } catch (e) {
    if (e.name === 'AbortError') return;
  }
  scheduleGroupReconnect(gid);
}

// 断开退避重连：1s/2s/4s（封顶）
function scheduleGroupReconnect(gid) {
  if (App.state.currentGroupId !== gid) return;
  const delay = App.state.groupBackoff;
  App.state.groupBackoff = Math.min(App.state.groupBackoff * 2, 4000);
  setBanner(`群聊连接断开，${Math.round(delay / 1000)}s 后重连…`);
  clearTimeout(App.state.groupReconnectTimer);
  App.state.groupReconnectTimer = setTimeout(() => {
    if (App.state.currentGroupId === gid) openGroupStream(gid);
  }, delay);
}
```

| GET/PATCH/DELETE | /groups/{id} | 详情（含 members）/ 编辑（运行中改成员 → 409 + code 1002）/ 删除（运行中先停止） |
| GET | /groups/{id}/messages?limit=200 | 群消息（倒序） |
| POST | /groups/{id}/start\|pause\|resume\|stop\|interject | 群控制（start 可带 {topic}） |
| GET | /groups/{id}/stream | 群流 SSE（status / turn_start / delta / turn_end / interject / error） |
| GET/POST | /sessions | 列表 / 创建 {title?, bot_id?} |
| PATCH/DELETE | /sessions/{id} | 改名 / 切换 bot_id / 删除 |
| GET/DELETE | /messages?session_id= | 消息（倒序）/ 清空；DELETE /messages/{id} 删除单条 |
| POST | /chat/stream | 单聊流式 SSE（delta / done / error） |
| POST | /chat/regenerate | 重新生成最后一条回复 |
| POST | /chat/stop | 中止进行中的生成 |
| POST | /export?session_id=&format=md\|json\|txt | 会话导出 |
| GET/POST | /config | 全局默认 API 配置 / 主题 / 代理 |

错误码：1001=默认机器人不可删除，1002=群状态冲突，1003=成员数越界（2-10），1004=含停用机器人。
