# Orua v5 实现计划：本地安全边界收敛与稳定性

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 Orua 的本地攻击面收敛到「只有本应用的浏览器上下文能调后端」，同时消除 Webhook 分派的无界线程增长，并把参数校验从「前端自觉」提升为「服务端强制」。

**Architecture:** 新增 header-only `validation.h`（clamp + 随机令牌）供 `backend` 与 `backend_tests` 共用；`server.cpp` 前置路由加令牌校验（仅对带跨域 `Origin` 的 `/api/v1/*` 请求，头像与 `/health` 豁免）；`skills.cpp` 加 DNS 解析后逐 IP 复检与 `file_read` 目录白名单；`event_bus` 从「每次 emit 一个 detached 线程」改为有界分派；WPF 读 `config.json` 注入令牌并在后端重启时重推；前端加 `authHeaders()` 回传令牌头。

**Tech Stack:** C++20 / cpp-httplib / SQLite / WinHTTP / WPF net8.0-windows / WebView2 / 原生 JS；测试 doctest + PowerShell 集成脚本 + Node stub 闸门 + WebView2 CDP 实机冒烟；LLM_MOCK=1 全链路可测。

**Spec:** `docs/superpowers/specs/2026-11-07-orua-v5-design.md`（计划逐条落实规格，冲突以规格为准）

## Global Constraints

- 显示名「Orua」，内部工程名 AiCompanion 不变；用户可见术语「Bot」。
- API 信封 `/api/v1` 统一 `{code,data}` / `{code,message}`；错误码沿用 1001-1004；**v5 不新增错误码**（令牌失败用 403）。
- 唯一模型来源 = 外部 OpenAI 兼容 API；`LLM_MOCK=1` 全链路可测。
- 数据目录 `data/`（app.db、uploads/、logs/）；测试只允许 tmp 临时目录与 data_e2e，**绝不读写 data/app.db**。
- v1–v4.1 全部自动化测试保持全绿；本计划内改动测试期望的任务必须同步更新断言。
- **不回归的既有不变量**：参数化 SQL、DPAPI + maskKey、calculator 无 eval 解析器、file_read 8KB 截断、http_get 2KB 截断 + SSRF 拒绝集 + 不跟随重定向、DOMPurify + marked、群引擎生命周期、迁移幂等性、失败可见性。
- **无 Origin 的本机直连必须继续可用**（`test_api.ps1` 零改动通过）——这是令牌设计的硬约束，不是妥协。

```cpp
#pragma once
// v5：服务端参数收窄与本地 API 令牌。header-only，供 backend 与 backend_tests 共用
// （server.cpp 只编进 backend，测试不链它，故不能把实现放 .cpp）。

#include <algorithm>
#include <cstdint>
#include <random>
#include <string>

namespace val {

inline int clampMaxTokens(int64_t v) {
  if (v < 1) return 1;
  if (v > 65536) return 65536;
  return static_cast<int>(v);
}

inline double clampTemperature(double v) {
  if (v < 0.0) return 0.0;
  if (v > 2.0) return 2.0;
  return v;
}

inline int clampKeepRounds(int64_t v) {
  if (v < 0) return 0;
  if (v > 100) return 100;
  return static_cast<int>(v);
}

inline int clampProxyPort(int64_t v) {
  if (v < 0) return 0;
  if (v > 65535) return 65535;
  return static_cast<int>(v);
}

// 32 字节随机熵 → URL-safe base64 无填充 → 43 字符。
// 每次后端启动生成一枚，写入 config.json 供 WPF 读取注入前端。
inline std::string randomToken() {
  static const char* kAlphabet =
      "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789-_";
  unsigned char raw[32];
  std::random_device rd;
  for (size_t i = 0; i < sizeof(raw); ++i) raw[i] = static_cast<unsigned char>(rd());
  std::string out;
  out.reserve(43);
  size_t i = 0;
  while (i + 2 < sizeof(raw)) {
    uint32_t n = (uint32_t(raw[i]) << 16) | (uint32_t(raw[i + 1]) << 8) | uint32_t(raw[i + 2]);
    out.push_back(kAlphabet[(n >> 18) & 0x3F]);
    out.push_back(kAlphabet[(n >> 12) & 0x3F]);
    out.push_back(kAlphabet[(n >> 6) & 0x3F]);
    out.push_back(kAlphabet[n & 0x3F]);
    i += 3;
  }
  // 32 = 3*10 + 2 → 剩 2 字节出 3 字符
  uint32_t n = (uint32_t(raw[30]) << 16) | (uint32_t(raw[31]) << 8);
  out.push_back(kAlphabet[(n >> 18) & 0x3F]);
  out.push_back(kAlphabet[(n >> 12) & 0x3F]);
  out.push_back(kAlphabet[(n >> 6) & 0x3F]);
  return out;   // 40 + 3 = 43
}

}  // namespace val
```

```cpp
void registerRoutes(httplib::Server& svr, const std::string& staticDir,
                    const std::string& authToken) {
  svr.set_pre_routing_handler([authToken](const httplib::Request& req, httplib::Response& res) {
    std::string origin = req.get_header_value("Origin");
    bool allowed = origin == "https://app.local" ||
                   origin.rfind("http://localhost:", 0) == 0 ||
                   origin.rfind("http://127.0.0.1:", 0) == 0;
    if (allowed) {
      res.set_header("Access-Control-Allow-Origin", origin);
      res.set_header("Access-Control-Allow-Methods", "GET, POST, PUT, PATCH, DELETE, OPTIONS");
      res.set_header("Access-Control-Allow-Headers", "Content-Type, X-Orua-Token");
    }
    if (req.method == "OPTIONS") {
      res.status = 204;
      return httplib::Server::HandlerResponse::Handled;
    }
    // v5 DNS-Rebinding 防护：仅当请求声明了跨域 Origin（即浏览器端）且已启用令牌时校验。
    // 无 Origin 的本机直连（test_api.ps1 / curl）不受影响；头像 GET 由 <img> 直接加载，
    // 无法携带自定义头 → 前导豁免。
    const std::string& path = req.path;
    bool apiPath = path.rfind("/api/v1/", 0) == 0;
    bool avatarGet = path.size() >= 7 && path.compare(path.size() - 7, 7, "/avatar") == 0;
    if (!origin.empty() && apiPath && !authToken.empty() && !avatarGet &&
        req.get_header_value("X-Orua-Token") != authToken) {
      res.status = 403;
      res.set_content(errJson(403, "缺少有效 X-Orua-Token").dump(),
                      "application/json; charset=utf-8");
      return httplib::Server::HandlerResponse::Handled;
    }
    return httplib::Server::HandlerResponse::Unhandled;
  });
  // ...
}
```

- [ ] **Step 4: 实现 `resolveAndRecheck`**

```cpp
// v5：DNS-Rebinding 防护。hostname 通过 isBlockedHost 后，解析出全部真实 IP 再逐个复检，
// 封死「先公网、后切回内网」。解析失败放行（连接稍后自然失败，不误伤离线环境）。
bool resolveAndRecheck(const std::string& host) {
  struct addrinfo hints{};
  hints.ai_family = AF_UNSPEC;
  hints.ai_socktype = SOCK_STREAM;
  struct addrinfo* res = nullptr;
  if (getaddrinfo(host.c_str(), nullptr, &hints, &res) != 0) return true;
  bool safe = true;
  for (auto* p = res; p; p = p->ai_next) {
    char buf[INET6_ADDRSTRLEN] = {0};
    if (p->ai_family == AF_INET) {
      auto* s = reinterpret_cast<sockaddr_in*>(p->ai_addr);
      inet_ntop(AF_INET, &s->sin_addr, buf, sizeof(buf));
    } else if (p->ai_family == AF_INET6) {
      auto* s = reinterpret_cast<sockaddr_in6*>(p->ai_addr);
      inet_ntop(AF_INET6, &s->sin6_addr, buf, sizeof(buf));
    } else {
      continue;
    }
    if (isBlockedHost(buf)) { safe = false; break; }
  }
  freeaddrinfo(res);
  return safe;
}
```

```cpp
// v5：file_read 目录白名单。允许 db::dataDir()、OS 临时目录、settings 里
// file_read_allowlist（分号分隔绝对根）显式追加的路径；其余一律拒绝。
bool fileReadAllowed(const std::string& rawPath) {
  namespace fs = std::filesystem;
  std::error_code ec;
  fs::path p = fs::u8path(rawPath);   // 输入按 UTF-8 构造，避免窄字节→ANSI 转换抛异常
  fs::path abs;
  if (p.is_absolute()) abs = p.lexically_normal();
  else abs = (fs::current_path(ec) / p).lexically_normal();
  if (ec) abs = p.lexically_normal();

  std::vector<fs::path> roots;
  std::string dd = db::dataDir();
  if (!dd.empty()) roots.push_back(fs::u8path(dd));
  std::error_code tec;
  auto tmp = fs::temp_directory_path(tec);
  if (!tec && !tmp.empty()) roots.push_back(tmp);
  if (auto extra = db::getSetting("file_read_allowlist")) {
    // 分号分隔
    size_t start = 0;
    while (start <= extra->size()) {
      size_t sep = extra->find(';', start);
      std::string one = extra->substr(start, sep == std::string::npos ? std::string::npos : sep - start);
      if (!one.empty()) roots.push_back(fs::u8path(one));
      if (sep == std::string::npos) break;
      start = sep + 1;
    }
  }

  for (auto& root : roots) {
    auto rn = root.lexically_normal();
    auto rel = abs.lexically_relative(rn);
    if (rel.empty()) continue;
    // rel 不得以 ".." 开头
    if (rel.u32string().rfind(U"..", 0) == 0) continue;
    return true;
  }
  return false;
}
```

> **注意**：`rfind` 的字面量必须是 `U".."`（`char32_t`），写成 `L".."`（`wchar_t`）在 MSVC 上无法匹配 `u32string::rfind` 的重载，编译直接失败——这条踩过。

```cpp
// event_bus.cpp — 有界分派：超出 kMaxInflight 进队列，队列满则丢弃最新
void EventBus::scheduleWebhook(WebhookJob job) {
  std::thread t;
  {
    std::lock_guard<std::mutex> lk(wm_);
    if (inflight_ >= kMaxInflight) {
      if (pending_.size() >= kMaxQueue) {
        logx::warn("event_bus: webhook 队列已满，丢弃一条");
        return;   // drop-newest
      }
      pending_.push_back(std::move(job));
      ++queued_;
      return;
    }
    ++inflight_;
  }
  t = std::thread([this, j = std::move(job)]() { /* httplib Client 2s 超时 */ finishWebhook(); });
  t.detach();
}
```
